# Strata VS Code theme

Light and dark theme for [strata](https://github.com/lgse/strata)
Both themes are inspired by the colors schemes from [Mofiqul/vscode.nvim](https://github.com/mofiqul/vscode.nvim)

## Installation

```bash
# clone this repository
git clone https://github.com/entirelysane/strata-vscode-theme.git

# copy theme files in strata config directory
cd strata-vscode-theme
cp vscode-dark.toml vscode-light.toml ~/.config/strata/themes
```

## Themes
- `vscode-light.toml` - light theme
- `vscode-dark.toml` - dark theme
